> peekaboo

Home Wi-Fi is a game of peekaboo: full bars when you stand next to the router, nothing the moment you sit down behind one wall. The word is funny at once because everyone knows the game, and it is true because every home has watched its signal vanish for no reason. It takes a surprising angle — a child's hiding game instead of the stock words like "slow" or "laggy" — and it reads in a single glance, eight plain letters, no context needed. It would also make a perfect network name: the router that hides from you.

## Run

```sh
node main.ts
```

Writes the word exactly, with no trailing newline, to `<MAKEFUN_OUTPUT_DIR or /output>/entry.txt`, mode 0644. Node 22.18 or later, standard library only, no network.
